# 🏥 Healthcare Utilization & Hospital Performance Dashboard

## 📌 Project Overview

This project focuses on analyzing healthcare utilization and hospital performance using Microsoft Power BI.

The dashboard provides insights into healthcare encounters, inpatient discharges, emergency visits, hospital facilities, health categories, and patient demographics.

## 🎯 Project Objectives

- Analyze healthcare encounters across different years.
- Identify the top 10 health categories.
- Compare healthcare encounters by setting.
- Identify the top 10 healthcare facilities.
- Analyze healthcare utilization by age group and gender.
- Provide interactive filtering through slicers.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Data Visualization
- Data Analysis

## 📁 Dataset Information

The project uses a synthetic healthcare utilization dataset containing 2,000 records for practice and analytical purposes.

**Note:** The dataset is simulated and does not represent actual hospital or patient records.
